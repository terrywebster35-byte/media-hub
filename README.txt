MEDIA HUB V1 — FRONT-END PROTOTYPE

Includes a responsive Media Hub interface with Movies, TV Shows and Music tabs, search, and a demo owner area. It is suitable as a design preview and can be installed as a PWA after being hosted over HTTPS.

IMPORTANT LIMITATIONS
- This is not yet connected to the Zyxel NSA310.
- Demo library entries are placeholders; there is no media streaming.
- Guest accounts, authentication, permissions and uploads are not implemented.
- A secure backend/gateway is required between the web app and the NAS. A browser cannot safely connect directly to SMB.
- Do not expose SMB, FTP, or the Zyxel admin page to the public internet.

To preview, the files must be hosted on an HTTPS web host or local web server. Open its address in Chrome and use the browser menu > Add to Home screen / Install app. Opening index.html directly as a file may not enable PWA features.
